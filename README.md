# Laundry-telegram-bot

Telegram-бот для автоматизации записи в прачечную общежития

---

## 💼 Как выглядит идеальный процесс работы

### 🔹 1. Обновить основную ветку

```
git checkout main
git pull
```

### 🔹 2. Создать новую ветку для своей задачи

```
git checkout -b feature/название-задачи
```

### 🔹 3. Работа над кодом

```
# редактирование файлов
```

### 🔹 4. Сохранить изменения

```
git add .
git commit -m "Краткое описание изменений"
```

### 🔹 5. Отправить ветку на сервер

```
git push -u origin feature/название-задачи
```

### 🔹 6. Создать Pull Request

После отправки ветки:

* зайти в репозиторий на GitHub
* нажать **Compare & pull request**
* проверить изменения
* нажать **Create pull request**
